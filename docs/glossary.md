
# Глоссарий проекта «Вечная память героям»

## Награды (Award System)

| Термин | Определение | Поле в proto |
|--------|-------------|--------------|
| **Award (Справочник)** | Запись в справочнике наград: название, тип, изображения, старшинство | `award.proto:Award` |
| **HeroAward (Привязка)** | Связь героя с наградой: дата, номер указа, знаки повторности | `hero.proto:HeroAward` |
| **Ribbon (Лента)** | Узкая полоса ткани на колодке, визуально представляет награду | `ribbon_image_url` |
| **Bar (Колодка)** | Металлическое основание для лент | - |
| **Order of Precedence** | Порядок старшинства наград (ГОСТ, приказ МО РФ №1500) | `type` + `is_jubilee` + `sort_order` |
| **Worn without bar** | Награда без колодки (звёзды, знаки) | `worn_without_bar` |
| **Device (Знак повторности)** | Доп. элемент на планке за повторное награждение | `HeroAward.devices[]` |
| **AwardType** | Классификация: `ORDER`, `MEDAL`, `BADGE` | `type` |
| **Звания (Hero titles)** | Звания «Герой РФ»/«Герой СССР» моделируются как `AWARD_TYPE_ORDER`, хотя семантически это не орден, а высшая степень отличия: тип используется только как ось старшинства компаратора, а `sort_order` + `worn_without_bar` дают корректное позиционирование (звезда — первой, без колодки). Отдельное значение enum — вне текущих срезов | `type = ORDER`, `worn_without_bar = true` |

## География (Locations)

| Термин | Определение | Поле в proto |
|--------|-------------|--------------|
| **Location** | Географический объект: город, населённый пункт, регион | `location.proto:Location` |
| **HeroLocation** | Привязка героя к локации с типом связи | `hero.proto:HeroLocation` |
| **HeroLocationType** | Тип связи: BIRTH, DEATH, BURIAL, RESIDENCE | `HeroLocation.type` |

## Конфликты (Conflicts)

| Термин | Определение | Поле в proto |
|--------|-------------|--------------|
| **Conflict** | Военный конфликт или операция | `conflict.proto:Conflict` |
| **HeroConflict** | Привязка героя к конфликту | `hero.proto:HeroConflict` |
| **ConflictType** | Категория конфликта: WAR, OPERATION, BATTLE | `Conflict.type` |

## Сид (Seed)

| Термин | Определение |
|--------|-------------|
| **Seed** | Детерминированный набор начальных данных для заполнения справочника при первом запуске |
| **Seed artifact** | Артефакт `seed.json` — JSON с данными и картинками (base64), собранный из исходников |
| **Seed builder** | Standalone Go-бинарник `cmd/seed-builder`, собирает `seed.json` из исходников |
| **Seed subcommand** | Subcommand `seed-awards` в бинарнике бэкенда для инкрементального импорта |
| **Bootstrap seed** | Автозапуск сида при старте приложения, когда справочник пуст |
| **One-shot container** | Одноразовый podman-контейнер, выполняющий команду и завершающийся |
| **Seed key** | Составной уникальный ключ `(name, type, jurisdiction)` для идемпотентности сида |
| **Ribbon (лента)** | Графическое представление награды на орденской планке (144×48 WebP) |
| **Bar (колодка)** | Металлическое основание для крепления лент наград |
