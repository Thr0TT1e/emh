# ADR-004: OpenLayers на публичной странице героя

## Статус
Принято (2026-09-16)

## Контекст
На странице `/heroes/[id]` нужно показать географию героя: место рождения, гибели, захоронения.
Данные приходят в `HeroDetail.locations` (массив `HeroLocation` с полными координатами).
В админке уже есть `LocationMap.vue` с OL — переиспользуем паттерн.

## Решение
Вариант A: карта только на `/heroes/[id]`, ленивая загрузка.

- Компонент: `app/components/heroes/HeroLocationMap.vue`
- Загрузка: `<ClientOnly>` + `defineAsyncComponent` (не входит в SSR-бандл)
- Источник тайлов: OSM (бесплатно, без ключа)
- Маркеры: цветные круги с подписями (тип локации + название)
- Тултип при наведении
- Легенда под картой (только для присутствующих типов)
- Тёмная тема: приглушение тайлов через CSS filter

## Альтернативы (отклонены)
- (Б) Карта на главной — усложняет первую загрузку, отложено
- (В) Страница `/map` — лишний роут, отложено

## Последствия
- ✅ Не влияет на TTI главной
- ✅ Карта грузится только на детальной странице
- ✅ ~200 КБ OL уходит в отдельный chunk (async)
- ❌ Нет кластеризации (если у героя >5 локаций — будет тесно)
  → Митигация: `fit(extent)` с `maxZoom: 12`
